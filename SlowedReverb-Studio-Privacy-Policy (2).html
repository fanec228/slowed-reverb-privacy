Slowed+Reverb Studio — Privacy Policy

Effective date: 19 November 2026 · Applies to browser extension version 2.1.0

Читать на русском

This policy describes how the Slowed+Reverb Studio browser extension handles data to provide real-time audio effects and user-requested diagnostics. The publisher is identified on the extension’s Chrome Web Store listing.

Audio processing

When you activate a preset or an effect, the extension processes audio from the selected browser tab on your device. Depending on the selected mode and browser support, it either connects effects to the page’s audio player or uses a live tab audio stream. Audio buffers are used in memory for processing and playback. The extension does not save audio recordings, upload audio, or access the microphone or camera.

Audio integration scripts load on HTTP and HTTPS pages and their eligible embedded frames to discover media elements and Web Audio connections, including players created before you enable an effect. Loading these scripts does not itself start tab audio capture or apply audio effects. You activate effects through the extension’s controls. Off stops live tab capture and disables the extension’s audio processing.

Settings, site information and diagnostic data

  • Settings and presets: language preference, audio parameters, feature preferences, and custom preset names and values are stored in the browser’s local extension storage. Per-tab effect state is stored in session storage.
  • Extension activity: when logging is enabled, a local log records up to 250 recent technical events, including timestamps, tab and frame identifiers, preset identifiers, effect parameters, processing modes and error messages. Logging is enabled by default and can be disabled. Existing logs can be cleared using the extension’s clear-logs control.
  • Website information: the extension uses the selected tab’s address to check eligibility. Media source addresses are inspected to determine their protocol and whether they share an origin with the page. A diagnostic report includes the selected website’s origin and embedded frame origins, such as scheme, domain and port; it does not include page paths or query strings as dedicated address fields.
  • Requested diagnostics: when you request a report, it contains browser and extension version information, selected settings, local technical logs, media playback and capture availability states, audio engine states and the site origins described above. It may include audio level and estimated BPM values, but no audio samples.

The extension does not intentionally collect identity or payment information, passwords, authentication cookies, account tokens, messages, track titles or general page text. Reports do not include custom preset names or full media source URLs. Common URL and credential patterns in logged strings are redacted, but a report still contains website origins and technical details; review it before sharing.

Purpose and sharing

This information is used only to apply your audio settings, retain your preferences, restore per-tab state and diagnose compatibility problems. The extension has no developer-operated data upload endpoint, external analytics or advertising service, and does not automatically send diagnostics to the developer or third parties.

You can explicitly copy a diagnostic report to the clipboard or download it as a local JSON file. If you then send that report to someone else, including a support service or an AI service, that is your separate sharing action and the recipient’s policies apply. The extension does not sell user data, use it for advertising or profiling, or use it for credit or lending decisions.

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Retention and your controls

Settings and custom presets remain in the browser until changed, deleted or removed with the extension’s local data. Logs retain at most 250 events and remain until cleared, overwritten by newer events or removed with the extension’s local data. Disabling logging stops new log entries and does not erase existing entries. Session state is removed as tabs are closed or the browser clears session storage.

Live audio streams and processing resources are released when processing stops or capture ends; audio is not retained as a recording. Downloaded diagnostic files and copies placed on the clipboard are outside extension storage and must be deleted separately. Uninstalling the extension removes its browser-managed storage; it does not delete files you downloaded or reports you shared.

Permissions

storage retains local settings, presets, session state and technical logs. scripting installs bundled audio integration code and gathers requested technical diagnostics in eligible tabs and frames. activeTab supports operations on the tab you select by invoking the extension. tabCapture provides a live audio stream from that selected tab. offscreen keeps the local audio engine running when the popup is closed. HTTP and HTTPS host access supports early player discovery and embedded players across websites.

All executable extension code is bundled with the installed extension. The extension does not load remote executable code. Restricting site access or revoking permissions can limit functionality.

Changes

If the extension’s data practices change, this policy will be updated to describe them. The policy date and applicable extension version appear above.

Slowed+Reverb Studio — Политика конфиденциальности

Дата вступления в силу: 19 ноября 2026 года · Для браузерного расширения версии 2.1.0

Эта политика описывает обработку данных браузерным расширением Slowed+Reverb Studio для применения звуковых эффектов в реальном времени и диагностики по запросу пользователя. Издатель указан на странице расширения в Интернет-магазине Chrome.

Обработка звука

После включения пресета или эффекта расширение обрабатывает звук выбранной вкладки на вашем устройстве. В зависимости от режима и возможностей браузера оно подключает эффекты к плееру страницы либо использует живой аудиопоток вкладки. Аудиобуферы используются в оперативной памяти для обработки и воспроизведения. Расширение не сохраняет аудиозаписи, не загружает звук на сервер и не обращается к микрофону или камере.

Скрипты интеграции загружаются на HTTP- и HTTPS-страницах и в доступных встроенных фреймах, чтобы обнаруживать медиаэлементы и связи Web Audio, в том числе созданные до включения эффекта. Само по себе это не запускает захват звука вкладки и не включает звуковые эффекты. Эффекты включаются через элементы управления расширения. Off останавливает захват звука вкладки и отключает обработку звука расширением.

Настройки, сведения о сайтах и диагностика

  • Настройки и пресеты: язык, параметры звука, предпочтения и названия и значения пользовательских пресетов сохраняются в локальном хранилище расширения. Состояние эффектов отдельных вкладок сохраняется в сессионном хранилище.
  • Действия в расширении: при включённом журнале локально сохраняются до 250 последних технических событий: время, идентификаторы вкладок и фреймов, идентификаторы пресетов, параметры эффектов, режимы обработки и сообщения об ошибках. Журнал включён по умолчанию. Его можно отключить, а существующие записи можно удалить кнопкой очистки журнала.
  • Сведения о сайтах: адрес выбранной вкладки используется для проверки возможности работы. Адреса источников медиа проверяются для определения протокола и совпадения источника со страницей. Диагностический отчёт содержит origin сайта и встроенных фреймов, то есть схему, домен и порт; пути страниц и параметры запросов не включаются в отдельные поля адресов.
  • Диагностика по запросу: при создании отчёта в него включаются сведения о браузере и версии расширения, выбранные настройки, локальные технические журналы, состояния воспроизведения, доступности захвата и звукового движка, а также указанные выше origin сайтов. Отчёт может содержать значения уровня звука и оценки BPM, но не аудиосэмплы.

Расширение не предназначено для сбора сведений о личности, платёжных данных, паролей, файлов cookie авторизации, токенов аккаунтов, сообщений, названий треков или обычного текста страниц. Пользовательские названия пресетов и полные адреса источников медиа не включаются в отчёты. Типичные шаблоны URL и данных авторизации в строках журнала скрываются, однако отчёт всё равно содержит origin сайтов и технические сведения. Перед передачей отчёта просмотрите его.

Цели использования и передача данных

Эти сведения используются только для применения настроек звука, сохранения предпочтений и состояния вкладок, а также поиска причин несовместимости. В расширении нет отправки данных на сервер разработчика, внешней аналитики или рекламных сервисов. Диагностика не передаётся разработчику или третьим лицам автоматически.

Вы можете самостоятельно скопировать диагностический отчёт в буфер обмена или скачать его как локальный JSON-файл. Последующая отправка отчёта кому-либо, включая службу поддержки или ИИ-сервис, является вашим отдельным действием; к получателю применяются его правила. Расширение не продаёт данные пользователей, не использует их для рекламы или профилирования, оценки платёжеспособности или кредитования.

Использование информации, полученной через API Google, соответствует Chrome Web Store User Data Policy, включая требования Limited Use.

Срок хранения и управление данными

Настройки и пользовательские пресеты хранятся в браузере до изменения, удаления или очистки локальных данных расширения. Журнал содержит не более 250 событий и сохраняется до очистки, вытеснения новыми событиями или удаления локальных данных расширения. Отключение журнала останавливает добавление записей, но не удаляет существующие. Сессионные данные удаляются при закрытии вкладок или очистке сессионного хранилища браузером.

Аудиопотоки и ресурсы обработки освобождаются при остановке обработки или завершении захвата; аудиозапись не сохраняется. Скачанные отчёты и данные в буфере обмена находятся вне хранилища расширения и удаляются отдельно. Удаление расширения удаляет его хранилище, которым управляет браузер, но не скачанные файлы и не отчёты, которые вы уже кому-либо отправили.

Разрешения

storage сохраняет настройки, пресеты, состояние сессий и технические журналы. scripting подключает код интеграции со звуком из пакета расширения и собирает техническую диагностику по запросу. activeTab поддерживает операции с вкладкой, на которой вы вызвали расширение. tabCapture предоставляет живой звук выбранной вкладки. offscreen обеспечивает работу звукового движка после закрытия всплывающего окна. Доступ к HTTP- и HTTPS-сайтам используется для раннего обнаружения плееров и работы со встроенными плеерами.

Весь исполняемый код входит в пакет расширения. Удалённый исполняемый код не загружается. Ограничение доступа к сайтам и отзыв разрешений могут ограничить работу функций.

Изменения

При изменении способов обработки данных эта политика будет обновлена. Дата и применимая версия расширения указаны выше.
